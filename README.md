# 빅 스토리 키우기 (BigStoryIdleRPG)

와우 포에버(World of Warcraft: Forever, 인터페이스 16001)용 방치형 키우기 애드온입니다.
메이플 키우기의 시스템과 수치(직업 스킬 배율, 전투 공식, 장비 등급, 드랍율, 소환 확률 등)를 그대로 쓰고,
겉모습(직업·스킬 이름, 아이콘, 몬스터, 지역, 장비 외형)은 WoW 클라이언트 에셋으로 바꿨습니다.
과금(BM) 요소는 모두 없고, 재화는 게임 플레이로만 얻습니다.

## 설치

1. 이 저장소의 `BigStoryIdleRPG` 폴더를 통째로 복사합니다.
2. 와우 설치 폴더의 `_classic_era_\Interface\AddOns\` (와우 포에버 설치 경로의 `Interface\AddOns`) 안에 붙여넣습니다.
   최종 경로: `...\Interface\AddOns\BigStoryIdleRPG\BigStoryIdleRPG.toc`
3. 게임 캐릭터 선택 화면의 [애드온] 목록에서 "빅 스토리 키우기"를 켭니다.

## 사용법

| 명령어 | 설명 |
|---|---|
| `/bsi` 또는 `/빅스토리` | 창 열기/닫기 (미니맵 버튼으로도 열 수 있습니다) |
| `/bsi arena` | 주변 애드온 사용자에게 내 정보를 알리고 결투장 상대를 찾습니다 |
| `/bsi minimap` | 미니맵 버튼 표시/숨김 |
| `/bsi debug` | 디버그 메시지 켜기/끄기 |

- 처음 열면 16직업 중 하나를 고릅니다. 직업은 WoW 직업·특성으로 표시됩니다 (예: 히어로 → 무기 전사).
- 전투 화면에는 **내 캐릭터의 3D 모델**이 나오고, 애드온에서 장착한 장비·무기 등급에 맞는 WoW 아이템 외형을 입습니다.
- 몬스터·보스는 챕터마다 대응하는 WoW 지역의 생물 모델로 나옵니다 (1~28챕터 필드, 29~40 던전, 41~47 공격대).
- 게임을 끄고 있던 시간만큼 방치 보상을 받습니다 (최대 24시간, 초당 0.9마리 기준).
- Lv30·60·100에 **전직 시험**(콘텐츠 → 전직 시험)을 통과해야 다음 차수의 스킬이 열립니다.
- **훈장** 탭: 성장·전투·보스 조건을 달성하면 훈장을 받아 보유 효과(주 스탯 +30, 최대 1,500 등)를 얻고, 하나를 착용해 이름 앞에 표시합니다.
- **보상** 탭: 일일·주간 미션, 특별 의뢰(마을 일회성 의뢰), 데일리 패스, 월간 출석, 무료 보상, 상점, 신규 14일 미션.

## 결투장 (PvP)

- 같은 애드온을 설치한 **길드원, 파티·공격대원, 애드온 전용 채널(BigStoryArena) 사용자**가 자동으로 상대 목록에 나타납니다.
- 상대의 전투 정보는 한 번 받으면 저장되므로, 상대가 접속을 끊어도 도전할 수 있습니다.
- 전투는 양쪽이 같은 난수 시드로 계산하는 자동 전투이며, 결과는 상대에게도 전달됩니다(방어 기록).
- 티어(브론즈~챔피언)는 알려진 애드온 사용자 사이의 순위로 정해집니다.
- 4주마다 **시즌 정산**으로 원작 콜로세움·월드 아레나 보상(스타포스 주문서, 미라클·에디셔널 큐브, 경험치 부스터)을 티어·순위에 따라 받습니다. 콜로세움·월드 아레나 자체는 없습니다.
- 저장 파일(SavedVariables)은 사용자가 고칠 수 있으므로, 결투장 결과의 공정성은 보장되지 않습니다.

## 폴더 구조

```
BigStoryIdleRPG/        애드온 (이 폴더만 설치)
  Core/                 이벤트, 저장, 숫자 표기, 난수, 직렬화, API 호환
  Data/                 생성된 게임 데이터 (tools/gen_*.py로 다시 만들 수 있음)
  Engine/               조건식 컴파일러, 스탯 계산, 데미지 공식, 스킬 연산 전투 엔진
  Systems/              성장 시스템, 콘텐츠, 결투장, 무료 재화
  Net/                  애드온 간 메시지 (분할 전송, 전송량 제한)
  UI/                   메인 창, 전투 화면, 각 탭
research/               수치 출처 자료 (추출·조사 결과, 출처 URL 포함)
tools/                  데이터 생성기, 헤드리스 테스트 (lua5.1)
```

## 데이터 출처

- 직업·스킬, 전투 공식, 챕터, 장비·소환·강화 수치: 메이플 키우기 클라이언트 1.18.0 기준 공개 데이터
  (mapleidleindex.com), 엘리트·동료·챕터 보상(mekipick.com), 공식 패치노트(넥슨 포럼), 글로벌 위키.
- 각 수치의 출처는 `research/spec/*.md`에 정리되어 있습니다.
- 공개 자료에 없어서 임시값을 쓴 항목은 코드에 `PROVISIONAL`로 표시되어 있습니다.

## 개발

```
python3 -I tools/gen_data.py      # 직업·스킬·챕터
python3 -I tools/gen_rewards.py   # 드랍·첫 클리어 보상
python3 -I tools/gen_items.py     # 소환·무기·동료·장비
python3 -I tools/gen_upgrades.py  # 스타포스·잠재·주문서·용사의 힘·어빌리티·유물·여정
python3 -I tools/gen_skin.py      # WoW 외형 매핑
python3 -I tools/gen_growth_rewards.py  # 성장 던전 단계별 보상(공개된 값만)
sh tools/test/run_all.sh          # 전체 테스트 (lua5.1 필요)
```
